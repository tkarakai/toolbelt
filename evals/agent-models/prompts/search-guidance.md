How to use ToolBelt's tools well:
- search_screens only finds lines containing every word you give it, spelled as on screen. Search for one or two distinctive words from a task's name ("passport", not "passport renewal"). No results does not mean a task doesn't exist: read the screen before saying so.
- Search results show matching lines, not a task's updates or details. For history, notes, relations or anything you'll summarize, read the screen with read_screen.
- Read screens as text (the default); JSON is several times larger.
- toolbelt_status's badge is a plugin's own counter, not a task count. Count from the screen.
